# EosHC

EosHC (Host Checker) is an ambitious passion project that is being created by a beginner programmer. Expect the project to be abandoned, unfinished or filled with errors.

Eos will be a desktop application with a user-friendly GUI that will, upon an input from the user, use several other pinging websites to check availability of websites, servers, hosts, IP addresses and domains' location data from a few geolocation IP databases and whois.

Developer entirely in Python.
